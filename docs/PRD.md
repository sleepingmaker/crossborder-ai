# CrossBorder AI — PRD v0.1

## 1. 产品一句话

帮助跨境电商新人和运营人员，基于已有商品、竞品、评论和社区讨论数据，快速生成结构化市场研究与 Listing 优化建议。

## 2. 当前要解决的问题

跨境电商市场调研往往分散在多个步骤和工具中：
- 看竞品 Listing；
- 看价格；
- 看评论和差评；
- 看 Reddit/社区讨论；
- 总结用户痛点；
- 判断产品机会；
- 再整理 Listing 优化建议。

对于新人，这些步骤耗时、方法不统一，也容易只做“信息搬运”而没有形成结构化判断。

## 3. MVP 用户

第一版只服务两类人：

1. 跨境电商新人：不知道如何系统做产品调研。
2. 跨境电商运营/产品研究人员：希望减少重复整理信息的时间。

## 4. MVP 输入

第一版不优先做自动爬虫。

用户可以提供：
- 商品关键词；
- 目标市场；
- Listing 文本；
- CSV/JSON 评论数据；
- 可选 Reddit/社区讨论文本。

## 5. MVP 输出

系统生成一份结构化研究报告：

1. 市场概览
2. 竞品分析
3. 价格区间
4. 高频关键词
5. 用户痛点
6. 差评集中问题
7. 用户画像
8. 产品机会点
9. Listing 优化建议
10. 风险提示

## 6. MVP 核心流程

```text
输入商品/市场信息
        ↓
数据清洗与结构化
        ↓
关键词与主题提取
        ↓
竞品/评论/社区讨论分析
        ↓
LLM 综合判断
        ↓
结构化市场研究报告
```

## 7. 第一版明确不做

为了避免项目范围失控，v0.1 暂不做：
- Amazon 大规模自动爬虫；
- 复杂反爬与验证码处理；
- 自动下单或广告投放；
- 多租户 SaaS；
- 完整跨境 ERP；
- 复杂权限系统；
- 多 Agent 炫技式编排。

这些能力只有在 MVP 跑通以后再评估。

## 8. 第一阶段成功标准

MVP 达标必须满足：

- 能输入至少一种真实商品数据；
- 能稳定生成结构化报告；
- 报告不是简单摘要，而要有“痛点 → 机会 → 建议”的逻辑链；
- 能保存至少一个完整案例；
- 能用 2~3 分钟完成产品演示；
- 项目负责人能讲清楚整个数据流。

## 9. 求职价值

这个项目需要同时证明三种能力：

### AI 产品能力
- 用户问题定义
- MVP 边界
- 工作流设计
- 输出质量评估

### AI 应用工程能力
- LLM 调用
- Prompt/结构化输出
- Tool/MCP 的后续扩展
- 数据处理与应用工程化

### 跨境业务理解
- 竞品研究
- 评论/差评分析
- 用户痛点挖掘
- Listing 优化
